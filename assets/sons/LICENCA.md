# Licenças dos efeitos sonoros

Todos os arquivos desta pasta são efeitos sonoros curtos, de bancos gratuitos.
Se quiser trocar algum por um som próprio (ex.: uma gravação engraçada do
grupo), é só substituir o arquivo — o nome tem que continuar o mesmo, porque
é ele que o código usa pra achar o som (veja `js/narrador.js`).
